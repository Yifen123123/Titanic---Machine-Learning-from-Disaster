## 📌 專案介紹
這是一個基於 Titanic 生還者預測的分類問題專案，目的是透過乘客的基本資料預測其是否能在事故中生還。
專案涵蓋資料讀取、前處理、探索性資料分析 (EDA)、建模與結果評估，完整實作機器學習專案流程。

## 🎯 專案學習目的
- 學習資料讀取與前處理技巧
- 熟悉探索性資料分析 (EDA) 與資料視覺化
- 實作分類型機器學習模型
- 評估模型表現與解讀結果
- 體驗完整資料科學專案流程

## 🤖 使用模型
### RandomForestClassifier
集成式學習 (Ensemble Learning) 的分類演算法，由多棵決策樹組成，透過投票機制決定預測結果。
對非線性資料與多維特徵的分類問題表現良好，且能評估特徵重要性。

##🌟 選用 RandomForest 的優勢
- 能處理數值型資料與特徵重要性評估
- 支援 early stopping，加速訓練過程
- 對於非線性資料表現良好
- 不易過擬合，適合分類型問題
